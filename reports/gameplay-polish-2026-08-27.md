# UI、难度曲线与提示系统打磨报告（2026-08-27）

> 用户发起，位于阶段 14（已完成）与阶段 15（pending）之间。非阶段提示词任务，不占用阶段编号。

## 任务范围

- UI：统一首页、HUD、选章、选关与操作区的视觉层级，强化《双生折线》的蓝/橙双角色识别。
- 难度：降低第一章中段和传送教学的突兀峰值，将第一章最高难度稳定放在章末。
- 提示：把底部小字号状态栏升级为常驻提示卡，增加显式提示按钮、建议方向高亮、受阻/单角色到达出口的动态反馈。

## 关键改动

### UI

- 首页删除 Phaser 与 DOM 重复绘制的标题，改为单一品牌区、双角色标记、进度胶囊和清晰的主操作。
- HUD 增加“当前步数 / 目标步数”并排指标和独立提示按钮；窄屏使用两行网格，保留 44px 触控目标。
- 选关格增加“教学 / 舒缓 / 进阶 / 挑战 / 章末”提示和 1–3 段难度标记。
- 棋盘与页面背景统一为冷白蓝灰体系，保留蓝/橙角色作为唯一高饱和视觉锚点。

### 提示

- 前三关建议方向按钮持续高亮；第 2 关提示改为明确的 `↑、↑、←` 行为说明。
- 点击 HUD 的 `?` 可随时恢复本关核心提示，并记录既有匿名 hint 遥测事件。
- 机关、传送、受阻和单角色先到出口时显示即时反馈，2.2 秒后自动恢复关卡核心提示。
- 选章与选关界面也提供常驻说明，避免状态栏残留上一场景信息。
