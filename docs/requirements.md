# 《双生折线》需求基线 V1.0（已冻结）

> 冻结日期：2026-08-22。来源：`reference/项目需求规格.md`、`reference/关卡机制与50关规划.md`、`reference/关卡JSON_Schema.md`、`reference/验收矩阵.md`。
> 变更纪律：任何影响 R-01~~R-07、M0~~M8、50 关要求或离线发布的修改，必须先在 `docs/decision-log.md` 登记 ADR，再同步更新本文件、测试与求解器。禁止静默修改。

## 1. 用户与主要场景

- **目标用户**：手机休闲解谜玩家；碎片时间单手竖屏操作；无年龄分层假设，默认成人认知水平。
- **主要场景**：
  1. 首次进入 → 首页 → 一键开始第 1 关 → 通过教学理解镜像规则 → 逐关推进（S1）。
  2. 老玩家再次进入 → 继续游戏 → 跳到最高解锁关（S2）。
  3. 卡关玩家 → 无限撤销 / 快速重开 / 局内提示（不代打）→ 自行解出（S3）。
  4. 优化型玩家 → 查看最佳步数与星级 → 重打低于目标步数（S4）。
  5. 干扰环境玩家 → 静音、弱化动画、振动开关 → 持久化（S5）。

## 2. 核心循环

观察双角色与双出口 → 输入一个方向（滑动或按钮）→ 蓝/橙按映射同步结算 → 达成/未达成 →（撤销/重开/继续）→ 双角色同回合各站对应出口 → 结算界面（步数、星级）→ 下一关。

循环外挂：章节/关卡选择、进度存档、设置、教学提示。

## 3. 范围与优先级定义

- **P0**：不交付即失败（核心规则、输入、通关、撤销、50 关、存档、教学、离线 H5、提交材料）。
- **P1**：交付即加分（星级、音频、振动、弱化动画、遥测）。
- **P2**：明确排除（见范围外）。

### 范围内

首页与继续、章节/关卡选择、设置；滑动+按钮输入；确定性同步移动；双出口通关；无限撤销与快速重开；5 章 ≥50 关；本地存档；局内教学与提示；星级与最佳步数（P1）；音乐/音效/振动/弱化动画（P1）；开发版本地遥测（P1）。

### 范围外（P2，禁止蔓延）

账号、云存档、排行榜、好友、多人、实时联网；运行时大模型、在线生成、广告、分析 SDK；剧情、养成、商城、复杂 3D、连续物理；以代码复杂度或美术数量为目标的功能。

## 6. 规则基线（R，冻结）

| 编号 | 规则                                                                   | 补充精化（决策出处） |
| ---- | ---------------------------------------------------------------------- | -------------------- |
| R-01 | 正交网格，每次输入上/下/左/右之一                                      |                      |
| R-02 | 蓝色执行原方向；橙色默认水平镜像（左↔右，上/下不变）                   |                      |
| R-03 | 单方被阻挡则停留，另一方仍移动                                         |                      |
| R-04 | 结算后同格则整步取消（双方及动态状态全部回退到该输入前）；允许对穿交换 | 阶段 02 形式化       |
| R-05 | 出口不锁定；二者同回合在各自匹配出口才通关                             |                      |
| R-06 | 无限撤销，恢复全部动态状态；提示不直接完成                             |                      |
| R-07 | 不限时，首次通关不限步数；目标步数仅作评价（见 ADR-003）               |                      |

## 8. 比赛提交约束（P0 材料）

1. 可断网运行的 H5 包（`dist/index.html` 单文件优先）。
2. 设计思路文档（与实际玩法一致）。
3. AI 协作与迭代文档（只含真实证据）。
4. README（运行、操作、浏览器、作者信息）。
