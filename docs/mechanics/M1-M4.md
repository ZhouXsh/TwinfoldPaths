# 机制手册 M1–M4（阶段 07）

> 面向后续阶段（08 高级机关、09 工具链、10 关卡生产）的机制事实说明。规则唯一事实来源仍是 `docs/turn-resolution.md` 与 `docs/decision-log.md`；本文件汇总 M1–M4 的语义、表现编码、关卡清单与测试地图。

## M1 普通压板与门

- 状态字段：`GameState.doors: Record<doorId, boolean>`；初始全关（`createInitialState`）。
- 阻挡（P4）：`door` 实体格在 `doors[id] === false` 时阻挡对应角色进入；**读取回合开始状态**——踩板与穿门不可同回合发生（时序无歧义）。
- 刷新（D4）：每回合末对每个 `plate`：`doors[plate.doorId] = 有角色（传送后）站在该板上`。离开即关闭（回合末），无独立记忆（I11）。
- 无压板联动的门保持关闭。
- 出口格永不阻挡（R-05）；关卡设计不得依赖"门压在出口上"。
- 已知未决：多压板联动同一 `doorId` 的语义未形式化（当前实现按实体数组顺序覆写）。阶段 07 关卡保持 1:1；阶段 09 校验器应禁止多板同门或以 ADR 定义 OR 语义。
- 关卡：教学 `level-011`（压板开门，par 5）；组合 `level-015`（M0+M1 墙体与门，par 7）、`level-017`（M1+M2 两类门的顺序，par 5）、`level-023`（M1+M3，par 4）、`level-029`（M1+M4，par 4）。

## M2 角色专属门

- 无状态字段（纯静态阻挡，P4）：`colorDoor.color !== 角色颜色` 时阻挡该角色；匹配颜色直接通过。
- 三重编码（NFR-05，禁止颜色作为唯一识别）：
  - 蓝门：蓝色 + 方形外框 + 横向条纹（`colordoor-blue`）。
  - 橙门：橙色 + 菱形外框 + 斜向条纹（`colordoor-orange`）。
- 角色本身已有形状差异：蓝=圆形、橙=菱形。
- 关卡：教学 `level-016`（角色专属门，par 3）；组合 `level-017`。

## M3 暂停格与暂停令牌

- 状态字段：`ActorState.hasPauseToken: boolean`，上限 1（ADR-005，I10）。
- 授予（D6，ADR-015）：本回合**新抵达**（移动或传送，最终位置≠回合开始位置）`pauseTile` 且无令牌 → 授予；原地停留（暂停消耗/被阻挡）不重授；离开后再踩可重新授予。
- 消耗（P3，ADR-002）：持令牌角色的下一次输入清除令牌，该角色本回合目标格=当前格（视为被自身暂停阻挡，`MoveResult.blocked=true`、`pauseConsumed=true`）；**回合照常计数**，另一角色与动态状态照常结算。
- 取消恢复（I6）：回合被 P5 同格取消时，令牌随全量回退恢复。
- 撤销恢复（I4）：令牌在 Snapshot 中，撤销完整还原。
- 表现：持令牌角色右上角显示圆形徽章（`token` 贴图，颜色+形状+纹理三重编码）；消耗回合状态行提示"×消耗暂停令牌，原地停留"。
- 关卡：教学 `level-021`（暂停令牌，par 4）；组合 `level-023`（暂停压板协作，par 4）。

## M4 映射切换器

- 状态字段：`GameState.mapping: MappingMode`（`H_MIRROR`/`V_MIRROR`/`ROTATE_CW`），初始取关卡 `initialMapping`。
- 生效（D3）：回合末（传送后）仍站在某 `switcher` 上的角色 → `mapping = switcher.target`；双角色站在不同目标的切换器上 → 蓝色优先（ADR-006）。
- 本回合方向仍按回合开始时的映射计算（P2，I18）；切换只影响后续回合。离开切换器后映射保持，直到下一次切换。
- **界面始终显示当前映射**：HUD `#mapping-label`（"映射：水平镜像/垂直镜像/顺时针旋转"），在进关、每回合末、撤销、重开时同步；切换回合状态行提示。
- 表现：切换器贴图按目标映射绘制箭头符号（`switcher-V` ↕、`switcher-H` ↔、`switcher-R` ↻）。
- 关卡：教学 `level-026`（垂直镜像切换，par 4）；组合 `level-029`（映射决定开门，par 4）。

## 组合顺序要点（集成测试覆盖）

- 同回合内 D3（切换器）与 D4（压板/门）各自独立生效，互不覆盖（`combo-d3d4` 用例）。
- 门状态读取回合开始状态；切换器同理（P2 只读回合开始映射）。
- 撤销恢复全字段（门、令牌、映射、位置、计数），多机制序列逐步撤销与初始状态逐字段相等（canonicalJSON/stableHash 双重断言）。
- 序列化与稳定哈希覆盖门、令牌、映射字段（I8）。
