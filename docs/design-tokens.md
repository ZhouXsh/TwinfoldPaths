## 4. 触控目标尺寸

| 目标       | 最小尺寸     | 备注                       |
| ---------- | ------------ | -------------------------- |
| 方向键     | 56×56 CSS px | 远大于 NFR-04 的 44px 要求 |
| HUD 按钮   | 44×44 CSS px | 撤销/重开/首页             |
| 设置开关   | 48×28 CSS px | 包含可点击区域             |
| 操作按钮   | 48×48 CSS px | 开始游戏、选关等           |
| 关卡网格格 | 56×56 CSS px | 每格含关卡编号             |

## 6. 动画

| 令牌         | 值             | 用途                 |
| ------------ | -------------- | -------------------- |
| `anim-move`  | 180ms          | 角色移动（可弱化）   |
| `anim-shake` | 120ms          | 受阻抖动（可弱化）   |
| `anim-win`   | 700ms          | 通关后延迟（可弱化） |
| `anim-delay` | 30ms           | 动画后额外等待       |
| `anim-ease`  | `Quad.easeOut` | 移动缓动函数         |

## 7. 响应式断点

| 断点 | 值         | 调整                                    |
| ---- | ---------- | --------------------------------------- |
| `xs` | ≤360px     | 关卡网格 4 列，章节网格 1 列，标题 24px |
| `sm` | 361–599px  | 默认竖屏布局                            |
| `md` | ≥600px     | 方向键加大（64px），关卡网格最大 420px  |
| 横屏 | 高度≤500px | 显示横屏提示                            |

## 8. 安全区

所有容器使用 `env(safe-area-inset-*)` 变量：

- `#app`：`padding-top/bottom/left/right` 使用安全区
- `.bar`：`padding-left/right` 使用 `max(8px, env(safe-area-inset-*))`
- `.overlay`：`padding-top/bottom` 使用 `max(20px, env(safe-area-inset-*))`
- `#bar-controls`：`padding-bottom` 使用 `max(8px, env(safe-area-inset-bottom))`
