# ADR-009：单文件离线构建

- 日期：2026-08-22
- 状态：accepted
- 影响需求：NFR-08、FR-06、AC-01/12、比赛提交约束
- 影响阶段：03、04、13、15

## 背景

交付物必须"无需网络、自包含 `dist/index.html`"（README 关键原则）。Phaser 体积大（压缩后约 1MB 量级），贴图/音频若走外部资产会破坏单文件与离线约束（RISK-05）。

## 候选方案

1. `vite-plugin-singlefile` 内联全部 JS/CSS；贴图程序化生成（Graphics/Canvas）、音频 WebAudio 合成；资产零外部文件。
2. 常规 Vite 多文件构建 + 打包脚本合成 HTML（base64 资产表）。
3. Service Worker 缓存多文件（非单文件）。

## 决策

方案 1。

## 理由与证据

`vite-plugin-singlefile` 是社区成熟方案，直接产出单文件，避免自写打包脚本的维护与正确性风险（方案 2）；方案 3 不满足"单文件"优先原则且微信内置浏览器对 SW 支持不稳（RISK-06）。程序化资产使总体积可控：预估单文件 1.5MB 以内（未实测，阶段 13 定预算并实测）。

## 后果

禁止代码分割与动态 import（构建配置显式关闭）；贴图/音频资产全部程序化（ADR-011）；`verify:dist` 扫描远程引用与密钥；体积超限触发程序化资产压缩或特效降级（实施计划降级顺序第 1 档）。

## 复查条件

实测体积超过 3MB 或低端机解析超时（阶段 13）时，评估 Phaser 定制裁剪构建。
