# ADR-008：领域层与表现层分离

- 日期：2026-08-22
- 状态：accepted
- 影响需求：FR-03、FR-05、NFR-07、AGENTS.md 纪律 4
- 影响阶段：03、05–13

## 背景

核心规则必须先存在于纯 TypeScript 领域层，动画不得修改逻辑状态。需要明确所有权边界与违规检测方式，否则 50 关工具链（求解器/校验器）无法在无浏览器环境运行。

## 候选方案

1. 严格分层：`src/domain` 零外部导入；表现层（Phaser）只读领域状态并消费 `MoveResult`；边界由脚本机器检查。
2. 宽松分层：允许领域层引用 Phaser 工具类型（如向量数学）。

## 决策

方案 1。

## 理由与证据

求解器（阶段 09）必须在 Node 内跑通全部机关，任何 Phaser 依赖都会使其需要浏览器桩；`scripts/check-deps.mjs`（本阶段引入）可机器强制该边界，成本约 60 行。方案 2 的便利（向量数学）可由 `Point` 自定义类型替代，无实际损失。

## 后果

`docs/architecture.md` §2 单向依赖表生效；所有规则测试（`docs/invariants.md` I1–I19）只依赖 `src/domain`；违规导入使 `check` 门禁失败。

## 复查条件

若出现确需共享的纯算法（如几何工具），放入 `src/domain` 而非放宽边界。
