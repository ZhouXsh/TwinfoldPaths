# ADR-021：探索难度、首页教学与第 11 关难度提示

- 状态：Accepted
- 日期：2026-08-28
- 修订：2026-08-29（选关入口难度同步与标准难度照明语义）

## 背景

全 50 关已经统一采用九宫格探索迷雾，但不同玩家对地图记忆与探索压力的接受程度不同。当前版本只有关卡自身的迷雾配置，没有一个面向玩家的全局难度入口；同时首页缺少集中教学，新的开放共享迷宫从第 11 关开始会出现明显难度跃迁。

## 决策

1. 首页新增三档“探索难度”，默认使用 **标准**：
   - **简单**：实际游玩时全地图常亮，不绘制迷雾遮挡。
   - **标准**：实际游玩时固定为角色周围 `square + radius=1` 的九宫格基础视野，双方共同提供视野；所有已经探索过的区域永久保持**完全点亮**，不得再覆盖半透明迷雾。
   - **困难**：实际游玩时同样固定为九宫格基础视野，但不保留离开后的探索记忆，只显示当前附近区域。
2. 难度只修改表现层信息可见性，不修改地图几何、机关状态、移动结算、胜利条件、`parMoves`、星级或 BFS 求解语义。
3. 难度保存到独立键 `twinfold-paths:difficulty`；清除游戏进度不清除玩家的难度偏好。
4. 首页新增“教学”按钮，以可滚动弹窗集中说明：胜利目标、蓝/橙映射、单侧受阻、同格取消、对穿、滑动/方向键、撤销/重开/提示，以及现有地图机关与三档探索难度。
5. 第 11 关的初始关卡提示以“难度飙升”开头，明确告知玩家从此进入开放共享迷宫与更长规划阶段。

## 实现约束

- `LEVELS` 继续保存原始正式关卡数据，校验器和求解器永远读取原始数据。
- `getLevelById()` 仅在提供给实际 GameScene 时，根据当前选择返回一个可见性覆盖后的关卡视图；不得原地修改正式关卡对象。
- 简单难度下需要同时去除游玩视图中的 `V1-fog` 标签，避免 GameScene 因标签继续创建迷雾层。
- 标准与困难难度都覆盖 `radius/shape/source` 为统一九宫格规则；标准使用 `memory=persistent`，困难使用 `memory=none`。
- `memory=persistent` 的历史探索格必须直接并入 `visible` 集合，因此标准难度下历史路径与探索区域完全点亮；仅 `memory=decay` 可以使用半透明 `remembered` 表现。
- 玩家从“继续旅程”“选关卡”“选章节”任一入口进入游戏时，都必须以 `twinfold-paths:difficulty` 的持久化值为事实来源。ChapterSelect / LevelSelect 进入时重新同步难度，LevelSelect 在真正启动 GameScene 前再次同步，防止场景跳转回退到默认难度。
- 关卡已有的雷达脉冲等额外字段可以继续保留，因此特殊关卡仍可在统一基础难度之上出现额外提示效果。

## 验收

- 单元测试覆盖三档可见性变换、默认值、持久化与原始关卡不可变性，并验证 `persistent` 历史探索区域进入 fully-visible 集合。
- Playwright 覆盖首页难度选择与刷新持久化、教学弹窗、第 11 关“难度飙升”提示，以及简单难度经“选关卡 / 选章节”进入时仍保持全图常亮、标准难度历史探索区域完全点亮。
- 现有 50 关 Schema / BFS / variety / build / offline dist 质量门不得下降。
