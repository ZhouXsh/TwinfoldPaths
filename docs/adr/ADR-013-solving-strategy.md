# ADR-013：求解策略（BFS + 稳定哈希判重）

- 日期：2026-08-22
- 状态：accepted
- 影响需求：CONTENT-04、FR-06、RISK-04、`reference/关卡机制与50关规划.md` 准入 2/3
- 影响阶段：03、09、10

## 背景

正式关卡必须"在预算内求解并能回放到胜利"。需要确定搜索算法、判重方式与预算策略，兼顾 M1–M8 引入的状态空间膨胀（RISK-04）。

## 候选方案

1. BFS（广度优先）+ `stableHash(不含 history 的状态)` 判重；设节点预算与深度上限；解=最短步数。
2. DFS/迭代加深：实现简单但不保证最短。
3. A* + 启发式：更快但需为各机关设计启发函数，复杂度高。

## 决策

方案 1。

## 理由与证据

最短解直接给出 `parMoves` 基准（ADR-003）与"最短解使用宣称机制"审计输入（CONTENT-04）；BFS 语义简单、可复现、易测试；50 关为小网格（约 ≤8×8）且单步移动，预算内可控。启发式在内容规模下收益不抵复杂度。

## 后果

`tools/solve-levels.mjs`：对每关跑 BFS，输出最短步数、节点数、解序列，并回放校验至胜利；超预算关卡判为不可收录（退回设计）；解序列存档供阶段 10 难度报告与回放测试。

## 复查条件

若第 4/5 章综合关普遍超出预算（节点爆炸），评估双向 BFS 或 A*，并同步更新预算定义。
