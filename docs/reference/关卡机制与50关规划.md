# 关卡机制与50关规划

## 机制词典

| 代码 | 机制 | 核心规则 |
|---|---|---|
| M0 | 墙与边界 | 阻挡单个角色，被阻挡者停留 |
| M1 | 普通压板/门 | 角色在板上时门开启，离开后回合末关闭 |
| M2 | 角色专属门 | 只允许对应角色通过，以颜色+形状+纹理编码 |
| M3 | 暂停格 | 获得一次暂停令牌，忽略下一输入后消耗 |
| M4 | 映射切换器 | H_MIRROR、V_MIRROR、ROTATE_CW 间切换 |
| M5 | 单向格 | 进入不限，离开必须符合箭头 |
| M6 | 传送门 | 回合末传送，每角色每回合最多一次 |
| M7 | 脆弱格 | 离开后坍塌为障碍，撤销必须恢复 |
| M8 | 同步脉冲 | 两角色同回合触发配对脉冲，开启终局门 |

## 五章曲线

| 章节 | 关卡 | 主题 | 目标 |
|---|---:|---|---|
| 镜像初识 | 1–10 | 墙体与位置解耦 | 理解一令双果 |
| 彼此开路 | 11–20 | 压板、门、专属通道 | 学会分工与协作 |
| 打破同步 | 21–30 | 暂停与映射切换 | 主动改变节奏 |
| 空间折叠 | 31–40 | 单向与传送 | 规划跨区次序 |
| 双线合流 | 41–50 | 脆弱格、同步脉冲、精选组合 | 综合推演与收束 |

## 正式关卡准入

1. Schema与语义校验通过。
2. BFS在预算内求解并能回放到胜利。
3. 最短解使用宣称的关键机制。
4. 有设计意图、标签、提示、目标步数和章节位置。
5. 与前后关不存在明显重复套路。
6. 算法难度不得冒充真人认知难度。
