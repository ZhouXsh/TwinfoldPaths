# 最终验收矩阵

| ID | 验收项 | 方法 | 通过标准 |
|---|---|---|---|
| AC-01 | 冷启动 | 清洁目录断网打开发布包 | 进入首页，无控制台阻断错误 |
| AC-02 | 核心输入 | 滑动和按钮分别执行 | 一次输入一个方向，动画期无重复结算 |
| AC-03 | R-01至R-07 | 单元与集成用例 | 所有规则用例通过 |
| AC-04 | 撤销/重开 | 含M1–M8动态状态 | 完整恢复；重开目标≤1秒 |
| AC-05 | 50关 | Schema、求解、回放、UI访问 | 50个唯一关全部可解可进入 |
| AC-06 | 难度递进 | 章节与机制覆盖审计 | 新机制先教学后组合，无连续机械重复 |
| AC-07 | 存档 | 刷新、前后台、损坏回退 | 进度和设置正确恢复 |
| AC-08 | 移动适配 | 320×568等视口 | 无关键遮挡、横向滚动、过小触控目标 |
| AC-09 | 无障碍 | 灰度、形状、设置 | 不依赖纯颜色，可关闭音效/振动/动画 |
| AC-10 | 浏览器 | Chromium、WebKit关键E2E | 均通过或真实记录环境阻塞 |
| AC-11 | 性能 | 可复现实测 | 满足需求预算或记录并关闭偏差 |
| AC-12 | 离线 | 禁网并扫描构建 | 无远程请求、无CDN、无密钥 |
| AC-13 | AI证据 | 审查迭代文档 | 问题—建议—判断—变更—验证可追溯 |
| AC-14 | 真人数据诚信 | 审查来源与版本 | 无伪造；无数据时明确标注 |
| AC-15 | 提交材料 | 文件清单与哈希 | H5、设计、迭代、README齐全一致 |

最终通过条件：P0缺陷为0；P1为0或有书面接受且不影响硬性要求；所有硬性需求有实际证据。
