## 2. 阶段展开（关键动作）

- **04**：`npm init` + 依赖锁定（`--save-exact`）；落地 §4 全部 npm scripts；ESLint/Prettier/TS strict；`scripts/check-deps.mjs` 接入 `check`；Vitest+Playwright 冒烟。
- **05**：实现 `src/domain`（`resolveTurn`、`undo`、`restart`、`projectSnapshot`、`stableHash`）；I1–I19 中引擎相关项逐条测试。
- **06**：Phaser 场景骨架（Boot/Home/LevelSelect/Game/Result）；输入归一化；存档双槽（ADR-001）；前三关（第 1–3 关数据）+ E2E。
- **07/08**：机关按机制词典实现；每机制先教学关样例验证再进内容。
- **09**：校验器（ADR-012）、求解器（ADR-013）、`parMoves` 核对（ADR-003）；编辑流程=手写 JSON+即时校验。
- **10**：按 `reference/关卡机制与50关规划.md` 逐关生产；难度报告区分算法难度与认知难度（CONTENT-05）。
- **11**：完整场景（ChapterSelect/Settings）；教学与提示；音频（ADR-011）；灰度/形状/纹理三重编码。
- **12**：单元/集成/属性测试补齐；domain 分支覆盖 ≥90%。
- **13**：Chromium+WebKit E2E；性能实测（未实测项标注）；单文件构建与 `verify:dist`；体积预算定值。
- **14**：认知走查 + 遥测工具（开发版）；真人试玩材料就绪但**不虚构**真人数据。
- **15**：RC 包、MANIFEST+SHA-256、README/设计/迭代文档。
- **16**：清洁环境复验、缺陷清零。
- **17**：归档与运行手册。

## 3. 工期降级顺序（RISK-09 映射）

触发条件：进度落后阶段表 ≥2 个阶段，或阶段报告连续两次标记阻塞。按顺序降级，**每降一档必须写 ADR**：

1. **第 1 档**：取消/简化 P1 表现层——遥测（FR-11）、音乐与振动（FR-10 降为仅音效）、弱化动画选项。存档结构保留字段（向前兼容）。
2. **第 2 档**：简化 M7/M8 组合——第 4/5 章综合关（第 40、45、48–50 关）允许降为 ≤3 机制组合；M7/M8 教学关（第 41、46 关）**不降级**。
3. **第 3 档**：关卡数量保底——50 关不降（P0），但允许将重复度高的备用关替换已规划关；章节主题不变。
4. **红线（绝不牺牲）**：核心规则 R-01~R-07 的正确性；50 关全部可解（求解器验证）；离线单文件交付。触碰红线=暂停并请求用户确认（P0 冲突）。
