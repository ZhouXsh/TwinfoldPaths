# O6｜后 30 关全量重制、整章探索与新机制扩展

## 目标

本轮不是对旧关卡做局部换皮，而是重新定义 21–50 的内容曲线：

1. `level-021..050` 全量重新生成地图、路径与机关组合，扩大棋盘并显著拉长 BFS 最短解。
2. 第四章 `031..040` 固定为完整的“暗域探索”章节，10/10 关采用迷雾，而不是零散插关。
3. 在九宫格基础上形成探索机制族：无痕迷雾、衰减记忆、交替双生视野、菱形/十字视野、周期雷达、永久视野信标。
4. 第五章新增 M9“奇偶相位门”，把回合节拍纳入逻辑状态；求解器必须正确区分奇偶状态。
5. 所有关卡 `parMoves` 禁止手填猜测，统一由 BFS 自动回填并在测试中要求 `parMoves === optimalSteps`。

## 执行拆分

### O6.1 规则与工具链

- 扩展 `LevelVisibility`，支持 shape / memory / source / radar。
- 新增 `visionBeacon` 表现层探索实体。
- 新增 M9 `phaseDoor` 领域实体。
- BFS 在存在相位门时把回合奇偶纳入稳定哈希。
- 关卡校验器解析新字段并强制第四章全章 fog。

### O6.2 后 30 关地图重建

- 使用确定性长廊/蛇形迷宫生成器，不复用旧地图。
- 第三章以 7×11、11×7、9×13、13×9、15×15 等大地图建立“扩域迷阵”。
- 第四章继续使用大地图，但信息受限，岔路主要服务探索与记忆。
- 第五章在大地图上叠加 M9 与 M1–M8，形成空间 + 时间双重约束。
- 后 30 关平均 BFS 最优步数验收门：`>= 18`。

### O6.3 parMoves 清零

- 生成后逐关调用 BFS。
- 不可解、超预算、最短解低于关卡最低复杂度目标时立即失败。
- 自动将 `parMoves` 写成真实 `optimalSteps`。
- 单元测试对全部 50 关做严格相等断言，不再接受“最短解 <= parMoves”。

### O6.4 自动化验收

必须通过：

- `npm run typecheck`
- `npm test`
- `npm run validate:levels`
- `npm run solve:levels`
- `npm run report:solution-variety`
- `npm run build`
- `npm run verify:dist`
- Chromium + mobile-320 E2E

额外统计：

- 第四章 fog 覆盖率 = 10/10。
- 后 30 关大地图比例 >= 80%。
- 后 30 关平均最优步数 >= 18。
- 同章节完全相同最短解 = 0。

## 验收原则

如果任意指标未达标，继续修改关卡生成参数或规则组合，不允许降低测试阈值来制造通过。最终只在全部质量门通过后合并到 `main`。
