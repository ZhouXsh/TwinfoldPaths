# 《双生折线》AI 全流程开发执行包 V2.0

这是一套直接驱动编码 AI 完成《双生折线》完整开发流程的 Markdown 文档。它不是传统需求书的简单转写，而是把需求、编码、测试、关卡生产、验收和参赛交付拆成 **18 个有强制验收门的阶段提示词**。

## 推荐使用方式

### 方式一：让同一个 AI 连续执行

1. 将本目录复制到目标代码仓库的 `docs/ai-dev-pack/`。
2. 将 `AGENTS.md` 复制到仓库根目录，或让 AI 明确读取它。
3. 把 `prompts/00_总控与执行协议.md` 作为第一次任务发送给 AI。
4. AI 应按 01→17 顺序执行；每阶段都必须生成报告并通过验收门。
5. 如对话上下文不足，开启新会话并让 AI 先读取 `.ai/project-state.md`、最近阶段报告和下一阶段提示词。

### 方式二：每阶段单独开启会话

依次发送 `prompts/01_...md` 至 `prompts/17_...md`。每次必须把同一个仓库和上阶段产物提供给 AI，不能只复制提示词而缺少代码与状态文件。

## 关键原则

- AI 可以完成编码、自动化测试、构建和技术验收，但不能虚构真人试玩。没有真人数据时，阶段14只可完成认知走查、自动遥测工具和试玩材料，并明确标记真实试玩尚未完成。
- `reference/项目需求规格.md` 是产品事实基线；阶段文档与其冲突时，以经过决策记录更新后的需求基线为准。
- `reports/` 和 `.ai/project-state.md` 是跨会话连续执行的核心，不应删除。
- 最终发布包必须无需网络，优先生成自包含的 `dist/index.html`。
