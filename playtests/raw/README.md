# 试玩数据存放说明

## 目录用途

本目录存放真人试玩原始数据。每个被试对应一组文件：

- `{player-id}-{date}.csv`：遥测模块自动导出的匿名事件记录
- `{player-id}-{date}-notes.md`：观察者填写的试玩观察记录

## 命名规则

- `player-id`：匿名编号，如 P01、P02……（不包含姓名、邮箱等身份信息）
- `date`：测试日期，格式 YYYY-MM-DD

## 数据格式

### CSV 遥测数据

由 `src/telemetry/telemetry.ts` 的 `exportCSV()` 导出，格式：

```
type,timestamp,levelId,moveCount,payload
level_start,2026-08-26T12:00:00.000Z,level-001,0,
move,2026-08-26T12:00:05.000Z,level-001,1,UP
...
```

### 观察记录（Markdown）

使用 `playtests/protocol.md` 中的观察表模板。

## 数据来源标注

所有分析报告必须标注数据来源：

- **真人试玩**：标注玩家编号、设备、日期、构建版本
- **AI 认知走查**：标注"非真人试玩，AI 认知走查"
- **自动分析**：标注分析方法

## 禁止事项

- 不得收集姓名、邮箱、设备 ID、IP 地址等身份信息
- 不得补写玩家未说过的原话
- 不得用 AI 模拟代替真人记录
- 不得将 AI 模拟数据写成真人测试结论
