# 《双生折线》试玩测试协议

> 版本：1.0
> 日期：2026-08-26
> 构建版本：Twinfold Paths MVP V0.7（阶段 13 完成）
> 用途：指导真人试玩测试的执行，确保数据收集一致、可追溯。

---

## 1. 测试目标

- 验证首关教学的理解门槛：玩家能否在无干预下自行发现镜像规则？
- 发现难度跳跃点：哪些关卡让玩家放弃或频繁重试？
- 收集撤销/重开模式：玩家在什么情况下使用撤销/重开？
- 验证反馈有效性：关卡提示、状态文字、动画反馈是否足够清晰？
- 收集口述策略：玩家如何描述两个角色的移动规则？

## 2. 测试环境

| 项目     | 要求                                                            |
| -------- | --------------------------------------------------------------- |
| 设备     | 手机竖屏（推荐 320–430px 宽度）或桌面浏览器窗口缩至竖屏比例     |
| 浏览器   | Chrome / Safari / Edge 最新版                                   |
| 运行方式 | 本地开发服务器 `npm run dev`，或直接打开 `dist/index.html`      |
| 遥测     | 通过 URL 参数 `?telemetry=1` 开启匿名事件记录（开发版默认开启） |
| 网络     | 断网可用（单文件离线 H5）；无需网络连接                         |
| 记录工具 | 本观察表 + 屏幕录制（可选，需被试同意）                         |

## 3. 被试招募要求

- 每个测试组至少 3 人
- 建议覆盖：有过解谜游戏经验 / 无此类型游戏经验
- 不收集姓名、邮箱、设备 ID 等身份信息
- 仅记录匿名编号（如 P01、P02…）

## 4. 测试流程

### 4.1 准备阶段（5 分钟）

1. 向被试说明：这是一个解谜游戏，你需要让两个角色都到达出口。
2. 告知被试：你可以随时撤销、重开、退出。观察者不会主动解释规则。
3. 告知被试：测试过程会记录匿名操作数据，不会收集个人信息。
4. 打开游戏，确保遥测已开启（开发版自动开启）。
5. 被试可以开始。

### 4.2 游戏阶段（不限时，建议 20–30 分钟）

1. 观察者记录行为，不主动干预。
2. 如果被试主动请求帮助，先记录"被试主动求助"，再给予最小提示。
3. 如果被试连续 3 分钟无进展，可以询问"你在想什么？"（不提供解法）。
4. 被试可以在任意时刻停止。

### 4.3 结束访谈（5 分钟）

结束后询问以下问题（见 §6）。

## 6. 结束访谈问题

1. 你认为两个角色是怎么移动的？（考察镜像规则理解）
2. 哪一关开始觉得有意思？为什么？
3. 哪一处最困惑？
4. 你认为最关键的一步是什么？
5. 你愿不愿意再玩一关？为什么？
6. （如果有关卡没完成）为什么那关放弃了？你当时觉得缺什么？

## 7. 数据诚信要求

- 观察记录与分析分开记录。不得补写玩家未说过的原话。
- 不得用 AI 模拟代替真人记录。
- 遥测数据（CSV 导出）与观察表分开存档，但可通过玩家编号关联。
- 数据文件命名格式：`playtests/raw/{player-id}-{date}.csv`（遥测）和 `playtests/raw/{player-id}-{date}-notes.md`（观察记录）。

## 8. 遥测数据格式

遥测模块自动记录的事件类型：

| 事件类型    | 触发时机                  | 附加数据   |
| ----------- | ------------------------- | ---------- |
| level_start | 进入关卡                  | 关卡 ID    |
| move        | 成功移动                  | 方向       |
| invalid     | 无效移动（同格取消/受阻） | 方向       |
| undo        | 撤销                      | 撤销后步数 |
| restart     | 重开                      | —          |
| hint        | 查看提示                  | —          |
| complete    | 通关                      | 完成步数   |
| quit        | 返回首页                  | 当前步数   |

导出 CSV 格式：`type,timestamp,levelId,moveCount,payload`

## 9. 数据来源标注

所有试玩报告必须标注数据来源：

- **真人试玩**：标注玩家编号、设备、日期、构建版本
- **AI 认知走查**：标注"非真人试玩，AI 认知走查"
- **自动分析**：标注分析方法（如 BFS 求解器分析）

严禁将 AI 模拟数据写成真人测试结论。
