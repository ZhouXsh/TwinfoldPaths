# 《双生折线》项目需求规格 V1.0


## 固定项目背景

- 项目名：**《双生折线》**，英文暂名 **Twinfold Paths**。
- 交付形态：手机竖屏、可离线运行的单文件 H5 休闲解谜游戏。
- 技术基线：TypeScript、Vite、Phaser 3、Vitest、Playwright；无后端、无账号、无在线模型、无 CDN。
- 内容目标：5 个章节、至少 50 个正式关卡。
- 核心输入：上、下、左、右四个离散方向，支持滑动与屏幕方向按钮。
- 核心规则：蓝色角色执行原方向；橙色角色默认执行水平镜像方向（左↔右，上/下不变）。
- 同步结算：某角色被墙或边界阻挡时，该角色停留，另一角色仍可移动；若结算后同格，则整条指令取消；允许对穿交换。
- 胜利条件：回合结束时，蓝、橙角色分别同时站在对应出口；提前到达的角色不会被锁定。
- 产品原则：不限时、首次通关不限步数、无限撤销、快速重开；目标步数只用于星级和优化挑战。
- 比赛关注：玩法、关卡体验、AI 驾驭力、迭代打磨；不以复杂美术、剧情或代码炫技为目标。


## 功能需求

| 编号 | 需求 | 优先级 | 验收摘要 |
|---|---|---:|---|
| FR-01 | 首页、继续游戏、章节/关卡选择、设置 | P0 | 加载后可一键开始，50关可按进度访问 |
| FR-02 | 滑动与方向按钮输入 | P0 | 一次手势只产生一个方向，动画期无重复结算 |
| FR-03 | 确定性同步移动 | P0 | 严格符合R-01至R-07，画面与逻辑一致 |
| FR-04 | 双出口通关与结算 | P0 | 同回合匹配出口才通关，显示步数与下一关 |
| FR-05 | 无限撤销与快速重开 | P0 | 恢复全部动态状态，重开目标不超过1秒 |
| FR-06 | 五章至少50关 | P0 | 关卡唯一、可解、递进、全部可从UI访问 |
| FR-07 | 本地存档 | P0 | 最高解锁、最佳步数、设置可恢复，损坏安全回退 |
| FR-08 | 局内教学与提示 | P0 | 新机制用演示/图标/短句，提示不直接代打 |
| FR-09 | 星级与最佳步数 | P1 | 不阻断通关，仅鼓励优化 |
| FR-10 | 音乐、音效、振动、弱化动画 | P1 | 可独立关闭并持久化 |
| FR-11 | 开发版本地遥测 | P1 | 匿名、可导出、正式版默认关闭 |

## 非功能需求

| 编号 | 类别 | 基线 |
|---|---|---|
| NFR-01 | 性能 | 目标60 FPS；回合逻辑目标小于16ms；首屏可交互目标小于3秒 |
| NFR-02 | 兼容 | Chromium、iOS/WebKit、微信常见内置浏览器；最小320×568 |
| NFR-03 | 稳定 | 连续10关无状态泄漏；刷新、前后台与存档正确 |
| NFR-04 | 可用 | 触控目标不小于44 CSS px；反馈目标100ms内出现 |
| NFR-05 | 可访问 | 颜色+形状+纹理；支持静音与弱化动画 |
| NFR-06 | 隐私 | 不收集身份；真实试玩匿名化；无第三方追踪 |
| NFR-07 | 可维护 | 关卡/代码分离；严格类型；领域规则有测试；Schema版本化 |
| NFR-08 | 发布 | 无CDN、无外部API、无密钥；优先单文件离线H5 |

## 范围外

- 账号、云存档、排行榜、好友、多人或实时联网。
- 运行时大模型、在线生成、外部广告和分析SDK。
- 剧情、角色养成、商城、复杂3D和连续物理模拟。
- 以代码复杂度、炫技或美术资产数量为目标的功能。

## 规则基线

| 编号 | 规则 |
|---|---|
| R-01 | 正交网格，每次输入上/下/左/右之一 |
| R-02 | 蓝色原方向；橙色默认水平镜像 |
| R-03 | 单方被阻挡则停留，另一方仍移动 |
| R-04 | 结算后同格则整步取消；允许对穿交换 |
| R-05 | 出口不锁定；二者同回合在匹配出口才通关 |
| R-06 | 无限撤销，恢复全部动态状态；提示不直接完成 |
| R-07 | 不限时，首次通关不限步数，目标步数仅作评价 |

## 版本变更

任何影响R-01至R-07、M0至M8、50关要求或离线发布的修改都必须写入 `docs/decision-log.md`，并同步更新测试、求解器和本需求。
